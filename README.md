# PJ-1ano

Um site desenvolvido para celebrar nosso primeiro ano de namoro.

## Sobre o projeto

Este projeto foi criado com HTML, CSS e JavaScript para homenagear um momento especial, com animações, fotos e uma interface romântica.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
